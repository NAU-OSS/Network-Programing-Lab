# Contributing to Network Programming Lab

Thank you for your interest in contributing to Network Programming Lab. 
This project is open to developers and learners who are interested in network programming.

## How to Contribute

You can make contributions in different ways. For example, you can report bugs, suggest new features, improve documentation, or contribute code.

For code contributions:

1. Fork this repository to your own GitHub account.
2. Clone your fork to your local computer.
3. Create a new branch for your changes.
4. Make and test your changes.
5. Commit and push your changes to your fork.
6. Create a pull request to this repository.
7. Describe what you changed and why in the pull request.

## Code Style

This project mainly uses C. Keep code simple and easy to read.

- Use meaningful names for variables and functions.
- Keep indentation consistent.
- Add comments when the purpose of code is not clear.
- Avoid unnecessary changes to unrelated code.
- Follow the style of the existing source code.

## Testing

Before a pull request, contributors should compile and test their changes.

Make sure the program can compile without errors and the basic client and server functions work correctly.
If a contribution involves new features, please make tests for new features before a pull request.

## Documentation

Contributors should update related documents when changes affect the project's running way.

New features should include a clear description and provide usage instructions if needed. 
If installation or usage changes, please update "README.md". 
Meanwhile, if comments can help other developers better understand the implementation logic, please add them.

## Reporting Bugs

If you find a bug, please create a GitHub Issue. The bug report should include:

- A clear description of the problem
- Steps to reproduce the problem
- Expected result
- The actual result
- Operating system or environment if it is related to the problem

Please check existing issues before creating a new one to avoid duplicate reports.

## Proposing New Features

New features can also be proposed through GitHub Issues.

Please describe what the new feature is, why it would be useful, and how it may improve the project. 
Discussion is encouraged before making a large change.

## Community Guidelines

All contributors should communicate respectfully and provide constructive feedback. Different ideas and experience levels are welcome in this project.

Contributors should follow the project's CODE_OF_CONDUCT.md when participating in issues, pull requests, reviews, and other project discussions.
